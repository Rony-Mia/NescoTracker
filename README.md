# NESCO Tracker — Updated Version

## নতুন কী কী যোগ হয়েছে
1. **সুন্দর ড্যাশবোর্ড** — একাধিক মিটার কার্ড আকারে দেখাবে, ব্যালেন্স কম হলে লাল রঙে alert ট্যাগ
2. **একাধিক মিটার/অ্যাকাউন্ট** — বাসা, দোকান, অফিস আলাদা আলাদাভাবে যোগ ও ট্র্যাক করা যাবে
3. **ব্যালেন্স হিস্ট্রি + গ্রাফ** — প্রতিটি মিটারের জন্য আলাদা লাইন-চার্ট
4. **দৈনিক গড় খরচ + কয়দিন চলবে** — অটোমেটিক হিসাব করে দেখাবে
5. **Low balance notification** — নির্দিষ্ট লিমিটের নিচে নামলে সাথে সাথে
6. **Recharge reminder** — প্রতি নির্দিষ্ট দিন পরপর (কাস্টমাইজযোগ্য) মনে করিয়ে দেবে
7. **Pull to refresh** — ড্যাশবোর্ডে উপর থেকে টেনে সব মিটার একসাথে রিফ্রেশ করা যাবে

## প্রজেক্ট সেটআপ করার ধাপ

### ধাপ ১: Android Studio-তে প্রজেক্ট খুলুন
1. এই পুরো `NescoTracker` ফোল্ডারটি আপনার কম্পিউটারে রাখুন
2. Android Studio ওপেন করে **File → Open** থেকে এই ফোল্ডার সিলেক্ট করুন
3. প্রথমবার খুলতে Gradle sync হতে কিছুটা সময় লাগবে (ইন্টারনেট লাগবে)

### ধাপ ২: অ্যাপ চালান
1. একটা রিয়েল ফোন (USB Debugging অন করে) অথবা Emulator কানেক্ট করুন
2. উপরে সবুজ **Run ▶️** বাটনে ক্লিক করুন
3. অ্যাপ ইনস্টল হয়ে চালু হয়ে যাবে

### ধাপ ৩: প্রথম ব্যবহার
1. `+` বাটনে চেপে আপনার প্রথম মিটার যোগ করুন (নাম + কাস্টমার নম্বর)
2. লো-ব্যালেন্স লিমিট আর রিমাইন্ডারের দিন সেট করুন (ডিফল্ট: ৳500, ৭ দিন)
3. Save করলেই সাথে সাথে একবার ব্যালেন্স চেক হয়ে যাবে
4. মিটার কার্ডে ক্লিক করলে ডিটেইল ড্যাশবোর্ড, গ্রাফ, usage estimate দেখতে পাবেন

## ⚠️ গুরুত্বপূর্ণ সতর্কতা
- **IP ব্লকের ঝুঁকি**: NESCO-র ওয়েবসাইটে খুব ঘন ঘন রিকোয়েস্ট পাঠালে আপনার IP ব্লক হয়ে যেতে পারে। এই অ্যাপে ডিফল্ট ৩ ঘণ্টা পরপর ব্যাকগ্রাউন্ড চেক সেট করা আছে — এটা কমানোর দরকার নেই।
- **ওয়েবসাইট পরিবর্তন হলে**: NESCO যদি তাদের সাইটের HTML গঠন পরিবর্তন করে, তাহলে `NescoChecker.kt` ফাইলের `label:contains(...)` সিলেক্টরটি আপডেট করতে হতে পারে।
- এই অ্যাপ শুধুমাত্র **নিজের** মিটারের ব্যালেন্স দেখার জন্য ব্যক্তিগত ব্যবহারের উদ্দেশ্যে তৈরি।

## Gradle sync error হলে
"Unable to find method ... DependencyHandler.module" জাতীয় এরর আসলে সাধারণত Gradle আর AGP-এর ভার্সন না মেলার কারণে হয়। এই প্রজেক্টে `gradle/wrapper/gradle-wrapper.properties` ফাইলে Gradle 8.4 (AGP 8.1.0-এর সাথে সামঞ্জস্যপূর্ণ) পিন করা আছে। তারপরও সমস্যা হলে:
1. Android Studio বন্ধ করে আবার খুলুন (**File → Invalidate Caches / Restart**)
2. নিশ্চিত করুন Android Studio-র Gradle JDK হিসেবে **JDK 17** সিলেক্ট করা আছে (**File → Settings → Build, Execution, Deployment → Build Tools → Gradle**)
3. **File → Sync Project with Gradle Files** চেপে আবার সিঙ্ক করুন (ইন্টারনেট লাগবে, প্রথমবার Gradle 8.4 ডাউনলোড হবে)

## প্রজেক্ট স্ট্রাকচার
```
app/src/main/java/com/example/nescotracker/
├── MainActivity.kt              → ড্যাশবোর্ড (সব মিটারের লিস্ট)
├── AddAccountActivity.kt        → নতুন মিটার যোগ করার ফর্ম
├── AccountDetailActivity.kt     → একটি মিটারের বিস্তারিত (গ্রাফ, usage, সেটিংস)
├── NescoChecker.kt              → ওয়েবসাইট থেকে ব্যালেন্স স্ক্র্যাপ করার লজিক
├── BalanceWorker.kt             → ব্যাকগ্রাউন্ড চেক + নোটিফিকেশন পাঠানো
├── NotificationHelper.kt        → নোটিফিকেশন তৈরি করার হেল্পার
├── SimpleLineChartView.kt       → কাস্টম গ্রাফ (কোনো external library ছাড়া)
├── AccountAdapter.kt            → RecyclerView অ্যাডাপ্টার
└── data/
    ├── Account.kt                → মিটার/অ্যাকাউন্ট এনটিটি
    ├── BalanceRecord.kt          → ব্যালেন্স হিস্ট্রি এনটিটি
    ├── AccountDao.kt / BalanceRecordDao.kt → Room database queries
    ├── AppDatabase.kt            → Room database
    └── Repository.kt             → সব বিজনেস লজিক (usage estimate সহ)
```
